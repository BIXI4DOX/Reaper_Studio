# Reaper Studio 7

A collection of scripts that utilizes more hotkeys than mouseclicks for various editing actions that are lacking or aren't available natively to Reaper.
If you dislike mouse-workflows or just want to do certain actions on a keyboard shortcut, then you'll love this reapository.

Alot of these script's editing features are inspired from various digital audio workstations such as **_FL Studio_**, **_Ableton_** & **_Block Head_**.
