# Reaper Studio 7

A collection of scripts that utilizes more hotkeys than mouseclicks for various editing actions that are lacking or aren't available natively to Reaper.
If you dislike mouse-workflows or just want to do certain actions on a keyboard shortcut, then you'll like what we have here.

Alot of these script's editing features are inspired from various digital audio workstations that me and my team can't live without, but it's mainly "FL Studio" & "Ableton".
